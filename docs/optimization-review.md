## 清理清单与保留理由

删除：

- `src/components/Rightside.astro`：全仓库无导入；导航/控制台已经承担相关操作。同步删除仅服务该未挂载组件的事件绑定，更新 README。
- `scripts/check-css-drift.cjs`：校验能力已合并到 `compile-css.cjs --check`。
- 图标字体 `.woff` 和 `.ttf`：与保留的 `.woff2` 是同一字体的旧编码副本；同步更新 CSS 引用，减少静态资源约 46.2 KiB。
- 未使用的 `themeConfigJSON()`、重复客户端函数和重复搜索样式。

保留：

- `stylus/` 与 `src/styles/theme.css`：分别是样式源与受校验的编译产物，不能当作无用重复文件删除。
- 字体子集工具、语言包、示例文章、内容模板和可配置扩展样式：均有明确用途，不能仅凭默认页面未引用某个 CSS selector 就删掉。
- GSAP / Typed / QRCode / LazyLoad：有条件加载路径，不属于无引用 vendor。
- `.astro/`、`dist/`、`node_modules/` 已被 Git 忽略；不把删除本地缓存当作代码优化成果。
