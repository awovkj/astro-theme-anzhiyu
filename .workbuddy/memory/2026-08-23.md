# 2026-08-23 项目评审（astro-theme-anzhiyu）

对 Astro 版 anzhiyu 主题做全面锐评，重新构建验证。核心结论：

## 实锤 bug
- `src/pages/search.json.ts:21` URL 双写：`url_for(`/posts/${p.path}/`)` 而 `p.path` 已含 `posts/` 前缀（collections.ts 8/23 00:52 改了语义未同步）。重建后 dist/search.json 输出 `/posts/posts/xxx/`，本地搜索全部 404。修复：去掉 `/posts/` 前缀。
- `TopHome.astro:71`：`return <a>{title}</a> && <div>{desc}</div>` —— && 丢弃左侧元素，swiper 标题链接不渲染。
- `PostCard.astro` / `TopHome.astro` 读 `article.content`，但 entryToPost 从不赋该字段（只有 `_entry.body`），首页摘要逻辑是死代码，全靠 description 兜底。

## 性能账本（与"速度敏感"目标冲突）
- theme.css 源文件 688KB / 27.6k 行；minified 后 568KB。Stylus 逐文件编译导致选择器大量重复（.content ×14、.modern ×13）。挂在 body 上全站加载。
- `public/font/hhh.ttf` 5.9MB 全量 TTF，@font-face "hhh" 直接用作 body 字体，未子集化。
- iconfont/typed.js/lazyload/qrcodejs 依赖 cdn.cbd.int（个人镜像，9 处硬编码）。
- build 仅 ~470ms（Astro 优势，值得保留）。

## SEO 硬伤
- 所有页面 `<link rel=canonical>` 和 `og:url` 都指向固定的 site.url（还是 example.com）。
- 无 sitemap / RSS；viewport 带 user-scalable=no。

## 工程化缺失
- 无 .git、无 .gitignore；astro-dev.log / preview.log 留在根目录。
- compile-css.cjs 依赖仓库外兄弟目录 `../../hexo-theme-anzhiyu`，且 cfg 为手抄镜像与 _config.yml 双源维护，必然漂移。
- README 说 iconfont 默认 cbd.int，代码实际 jsdelivr，文档失真。
- Hexo 嵌套 categories、sticky/top front-matter 字段 schema 不支持，blogcode 迁移会静默丢数据。

## 亮点
- remark-hexo-tags.mjs（sentinel 机制处理 inline 节点）质量最高。
- loadData 模块级缓存、客户端 runtime 零依赖重写、iconfont media=print 异步加载是最佳实践。
