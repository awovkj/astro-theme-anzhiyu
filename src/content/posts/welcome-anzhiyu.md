## 关于本主题

**安知鱼（AnZhiYu）** 是一款卡片风格（Card UI Design）的博客主题。本仓库将其从 Hexo 重构为 [Astro](https://astro.build)，保留了原始样式与视觉风格，同时用 Astro 内容集合与原生组件替换了 Pug 模板。

### 主要特性

- 卡片式文章列表与侧边栏小部件
- 暗色 / 亮色主题切换
- 文章目录（TOC）、归档、标签、分类页
- 与原主题一致的 CSS（由 Stylus 编译而来，样式保持不变）

### 快速开始

```bash
npm install
npm run dev
```

> 提示：图标字体通过 CDN 加载，请确保网络可访问 `cdn.cbd.int`。
